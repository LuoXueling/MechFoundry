Tool note: the skill names the tools of another agent harness. Here they map as follows, and where the skill and this note differ, this note wins.
- "Read" a file (a `read` field's `file:a-b` means lines a to b): run `sed -n 'a,bp' FILE` in the shell, or `cat FILE` for a whole file. "Grep" and "Glob": `rg` and `ls`. These read-only commands are allowed, for the skill folder and your session folder only, as rule 3 says; the skill's "any other shell command is refused" and "never cat, wc, head or tail" do not apply to them here.
- "Write" and "Edit" (the brief, plan.json, the judgement): `apply_patch`, which is a shell command here. Give it the patch on stdin with a quoted heredoc, as one exec_command whose text has real line breaks: `apply_patch <<'PATCH'`, then `*** Begin Patch`, the `*** Add File: PATH` / `*** Update File: PATH` sections, `*** End Patch`, and `PATCH` on the last line; paths under your session's operator/ folder. That heredoc is the one allowed: never pass the patch as a quoted argument (a "\n" inside quotes is not a line break), and never write files with cat, echo, tee, sed -i or python.
- "Look at a picture with the file reader": the view_image tool with the picture's path.
